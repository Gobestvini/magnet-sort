# Casual design — первый перенос в игру

2026-10-09. [План](../design/CASUAL_MIGRATION.md), [English reference](../design/mockups/2026-10-09-facebook-casual/index.html).

## Результат

Активный Three.js-прототип использует яркую фиолетово-синюю тему: оригинальный hex-фон, цветной логотип, светлые панели с золотистой кромкой, английский HUD, объёмные SVG-магниты без декоративных знаков, Hint/Restart. Основная композиция остаётся вертикальной на desktop и portrait; короткий landscape использует боковые controls.

Поле сохраняет 25 настоящих клеток и исходные уровни. Клетки и кольца имеют скруглённый hex-контур/кромку, отверстия колец — hex. Материалы освещены сценой и процедурным environment. Символы убраны и с колец; X препятствий остаётся. Правила, маршруты и профиль поштучных перелётов не изменены.

Пауза, победа, поражение и ошибка renderer используют светлые модальные панели; фон блокируется через inert, фокус остаётся в модальном окне, Escape продолжает игру из паузы. Карточка обучения берёт текст текущего уровня; подсказка выделяет реальную клетку, invalid placement объясняется через live status. DOM +6 появляется из текущего события очистки; счётчик увеличивается после конца соответствующего события.

В HTML есть короткая загрузочная заглушка без выдуманного процента. Runtime удаляет её перед монтированием Preact. Retry после ошибки WebGL использует существующий initialization contract.

## Ресурсы

- `public/art/casual-hex.svg`: оригинальный кодовый фон, SVG 96 × 112, повторяется CSS. Не требует JS-loader/GPU-ресурсов приложения.
- Логотип, магниты и Hint icon: оригинальные SVG/DOM в `src/prototype/App.js`, с CSS-тенями и градиентами. Надписи и счётчики — живой DOM, не вырезанные PNG.
- RoomEnvironment — модуль установленного Three.js; API/cleanup сверены с его локальными исходниками. PMREM target создаётся один раз на board, переиспользуется при reset и освобождается владельцем board. Временные environment scene/generator освобождаются сразу.
- Nunito — прежний локальный font с сохранённой лицензией. Полные мокапы остаются в документации, не грузятся в игру.

## Проверки

- `pnpm check:full`: unit tests и production build.
- `GAME_BASE_URL=http://127.0.0.1:5174 pnpm test:browser`: Chromium headless, desktop 1280 × 900, mobile viewport 390 × 844 и landscape 844 × 390; tap/drag/keyboard, invalid placement, input lock, pause/resume, mid-transfer reset, pointercancel, blur/синтетический hidden, все три авторских решения, reduced motion, loss/retry, resize, dispose.
- Browser suite проверяет английский UI, отсутствие оставшейся загрузочной заглушки и inert фона при паузе. 20 reset сохраняют число geometries/textures; ошибки страницы/console/HTTP отсутствуют.
- Дополнительная локальная проверка `artifacts/check-casual-ui.cjs`: ширина 320 px без горизонтального переполнения, modal focus/Tab/Escape, inert, синтетический context lost и Retry. Результат: `artifacts/three-browser/casual-extra.json`.
- Просмотрены актуальные screenshots initial/mixed, pause и результаты. Скриншоты/отчёт suite лежат в `artifacts/three-browser/`; полные test/build logs — `.telegram-check-logs/`.

Это browser surrogate, не проверка реального телефона. Новый environment добавляет стоимость shading/памяти: 60 FPS/p95 на Pixel 6a не измерены и не заявляются.

## Границы первого переноса

Реализовано направление, а не пиксельное совпадение AI-картинок. Модель и точные 25 клеток приоритетнее иллюстративного поля. Кодовые логотип/иконки, освещение и bevel отличаются от AI-рендера; отдельный этап художественной доводки может уточнить их по пользовательской оценке. Полного набора отдельных растровых ассетов не создавалось: текущий экран построен адаптивно из DOM/SVG/Three.js.

Подсказка пока объясняет координаты через status вместо нарисованного speech bubble. Payoff использует shrink существующих units и +6, без нового particle engine/конфетти. Цветовые названия доступны assistive technologies; режим для нарушений цветовосприятия без опоры на цвет пока отсутствует по выбранной версии без символов.

Legacy Pixi, контент уровней, экономика и публикация не изменены. Игра и Telegram не публиковались/не запускались.
