# Перебалансировка сложности кампании

Дата: 2026-10-07. Запрос: убрать одноходовые лёгкие уровни и добавить необходимость планирования.

## Результат

Переработаны все 45 уровней кампании 6–50, contentVersion повышен до 2. FTUE 1–5 сохранён как обучение. Модель правил не менялась. Поля содержат 9–18 фишек нескольких цветов, 9–18 препятствий и, в последнем band, 2–4 ящика. Цель — очистить всё; лимит равен длине сохранённого решения.

| Уровни | Длина сохранённых решений |
| --- | --- |
| 6–10 | 3 хода |
| 11–20 | 4–6 ходов |
| 21–35 | 5–8 ходов |
| 36–50 | 6–9 ходов |

Решения найдены ограниченным beam search и воспроизведены настоящим simulator; это свидетельство проходимости, а не доказательство оптимального числа ходов. Отбор включает случайную игру и случайные размещения при известной последовательности цветов, чтобы сложность не сводилась к выбору цвета. JSON фиксирован; авторинг не выполняется в игре.

Новые seed/contentVersion отделяют результаты от старых рекордов. Прогресс открытия уровней сохраняется. Старые вызовы для прежнего контента отклоняются existing version validation.

## Проверки

- Все 122 unit tests прошли: 50 авторских replays, баланс массы на каждом ходе, crate clear ordering, полный перебор легального первого хода в 45 новых полях без одноходовых побед.
- Две независимые случайные политики по 100 прогонов на каждый новый уровень: произвольные легальные действия; сохранённый порядок цветов со случайными клетками. Пороговые регрессионные проверки прошли.
- `pnpm check:full` прошёл в изолированном checkout базы `85b20e6` с изменениями только этой работы.
- `pnpm test:browser` прошёл в изолированном checkout: desktop и mobile viewport, многоходовые кампании/вызовы, подсказка, level 50 с ящиками, replay/retry, pause/reset/hidden и отсутствие runtime errors. Скриншоты просмотрены; журналы и снимки сохранены в `artifacts/campaign-difficulty/`.

В основной общей папке unit tests также прошли, но первая сборка/browser попытка застала параллельное удаление `src/ui/App.js`. Чужие изменения интерфейса не редактировались и в проверочный checkout не переносились.

Физический телефон, пользовательские оценки сложности и доказательство оптимальности всех решений не проверялись. Chromium с мобильным viewport — браузерный surrogate.
