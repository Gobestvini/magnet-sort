# Уплотнение башни и перелёт в CLEARED

2026-10-11. Активный Three.js-прототип, обе темы UI.

Референс пользователя: локальный `5357406101811801965.mp4` (864×1920, 5.27 с). Участок 3–5 с просмотрен через декодированные `requestVideoFrameCallback` кадры: после соседнего переноса красная башня сжимается вниз примерно на 3.87–4.41 с, появляются искры, затем маленький хекс летит со шлейфом к HUD. Первая нарезка через seeked показывала повторённый кадр и для анализа не использована. Контактный лист: `artifacts/gameplay-counted-hex/collect-reference.png`.

В игре перед каждым сбором хексы уменьшаются по одному сверху вниз: каждый за .20 с, со stagger в пределах .48 с на всю группу. Это заменяет первоначальное одинаковое масштабирование всех слоёв. Каждый ID имеет собственный progress; ещё не запущенные нижние элементы остаются полного размера. Высота верхнего складывается из шага каждого нижнего слоя, исключая прохождение сквозь него. Конечный масштаб отдельного хекса — .38, цифра башни скрывается на время уменьшения. После акцента .07 с элементы стартуют сверху вниз с интервалом .05 с и летят .56 с по слегка разным дугам, плавно раскрываясь до прежнего размера перелёта. Шлейф повторяет кривую, на старте и при попадании появляются небольшие светлые частицы; цифра счётчика мягко пульсирует. Показание CLEARED увеличивается на один при каждом прибытии. Завершение уровня ждёт последнего прилёта и короткого затухания эффекта. Тайминги — настройки игры по референсу, не точное измерение видео.

Модель и правила не изменены. `motion.js` — чистая timeline с compaction/launch/arrival. `board.js` показывает ID до handoff, затем `collection.js` показывает тот же ID как DOM-фишку из имеющегося PNG. Сжатие — временная визуальная деформация, а не изменение числа элементов. При обычном движении board + HUD flight + collected сохраняют initialUnits. Оставшиеся в стопке фишки продолжают входить в её цифру. Reduced motion убирает перелёт через экран, шлейф и частицы, сохраняя поштучное начисление.

Все эффекты используют sampled time единственного runtime RAF: pause/hidden/blur замораживают его, reset удаляет sprites/SVG и отменяет начисления, resize/scroll заново проецируют начало и цель, dispose освобождает слой. SVG-примитивы переиспользуются; эффект не добавляет GPU-геометрий, postprocessing или таймеров. Удалён прежний DOM +6. Preview adapter обновлён для поэлементного удаления, а не прежнего одновременного исчезновения всей группы.

Проверки:

- `tests/collection.test.js`: normal/reduced, порядок compaction → launch → arrival, уникальные ID и conservation на 120 Гц, одно начисление при прибытии, отсутствие повторного начисления при пересэмплировании, ожидание последнего прилёта.
- `tools/chip-browser-check.cjs`: 787 WebGL-кадров, 1245 соседних перелётов, контур основания внутри плитки, реальный индекс компактного слоя, верхние цифры, шесть GPU-геометрий без роста и 12 проверенных пикселей подложки X.
- `tools/collection-browser-check.cjs`: mobile viewport 390×844, desktop 1280×900 с resize до 430×932 во время полёта, reduced motion. 12 отдельных начислений и 12 уникальных sprites в обычном режиме; pause во время compaction и flight, заморозка SVG, UI Restart, cleanup, цель перелёта и ограниченный пул (<160 SVG-примитивов в проверенном сценарии).
- `pnpm check:full`: тесты и production build. `tools/browser-check.cjs`: общий сценарий UI, pause/reset/hidden/blur, ввод и lifecycle.
- Дополнительно те же collection/chip browser-сценарии прошли с точным board из подготовленного коммита и magnet-glow из HEAD, подставленными через локальный Playwright route: эффект работает независимо от параллельных незакоммиченных изменений draw-order/glow. Логи: `collection-owned.log`, `collection-chips-owned.log`.

Доказательства на диске: `artifacts/gameplay-counted-hex/collection-{full,chips,browser,integration}.log`, `artifacts/collection-browser/report.json`, `mobile-flight.png`, `desktop-flight.png`, `collection.gif`. Кадры фактической игры осмотрены: compact packet остаётся на месте ячейки, дуги сходятся к CLEARED, шлейф находится позади фишек. Это автоматический headless browser surrogate и просмотр его кадров; ощущение на реальном телефоне и его производительность не измерены.
