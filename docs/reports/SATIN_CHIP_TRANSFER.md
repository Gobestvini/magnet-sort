# Satin-фишки в активной игре

2026-10-11. Пользователь разрешил перенести понравившиеся сгенерированные фишки из мокапа в действующую Three.js-игру. Это расширение за пределы прежней подготовки макета в Figma.

## Источник и результат

`public/art/mockup/chip-{violet,blue,coral}.png` скопированы из одноимённых файлов `docs/design/prototypes/gameplay-counted-hex/painted-study/`. Источник генерации и промпты сохранены в README той папки. `public/art/mockup/tile.png` заменён на `docs/design/prototypes/gameplay-counted-hex/assets/tile-cream.png`.

PNG используется для верхней грани; UV исключают нарисованную боковину. Физическая боковина, фаска и тонкий нижний край остаются объёмными при перелёте и перевороте. Радиус 0.4352, суммарная толщина одного элемента 0.064, край 0.012. Мягкий свет боковин согласован с отражением верхней грани. Уменьшенная фишка оставляет бордер ячейки открытым; привязка плитки учитывает центр внутреннего углубления. Шаг рядов соответствует регулярной hex-сетке.

Каждому ID модели соответствует одна группа фишки. Счётчик вычисляется из непрерывной верхней группы цвета стоящих элементов: при взлёте число уменьшается, при посадке увеличивается, при очистке исчезает. Timeline и правила переноса не заменены декоративной анимацией.

## Проверки

- `node --test tests/chip.test.js`: сплошной центр, физическая толщина, посадочный радиус, UV, пустые/смешанные/20-элементные группы — успешно.
- `GAME_BASE_URL=http://127.0.0.1:5174 node tools/chip-browser-check.cjs`: 782 кадра всех трёх уровней с обычным и уменьшенным движением; точные ID, отсутствие дублей, позиции, высота, перелёты и счётчики. 1237 — сумма активных перелётов по проверенным кадрам, не число уникальных событий. Шесть GPU-геометрий сохраняются при reset. Стопка из 20 элементов проверена при ширинах 320, 390, 430. Отчёт: `artifacts/chip-browser/report.json`.
- `GAME_BASE_URL=http://127.0.0.1:5174 node tools/browser-check.cjs`: desktop/mobile viewport, управление, пауза, reset, reduced motion, ресурсы — успешно.
- `pnpm check:full`: тесты и сборка прошли. Лог: `artifacts/gameplay-counted-hex/chip-check-full.log`.
- Ручная браузерная проверка: размещение магнита, победа, переход на второй уровень и композиция всех трёх цветов. Снимок: `artifacts/gameplay-counted-hex/chip-game-proof.png`.

Проверка viewport не заменяет реальный телефон и не подтверждает мобильную производительность. У высокой стопки 20 тонкие края видны, но ручной пересчёт на маленьком экране затруднён; точное число даёт счётчик. Это перенос фишек и их посадки, не заявление о полном попиксельном совпадении экрана: сохранены три авторских уровня и существующая игровая оболочка.
