# Цельные плашки и рамки — 2026-10-11

По скриншотам HUD и карточки магнита воспроизведены светлые разрывы на краях. Причина — стыки областей `border-image`, растягиваемых независимо при дробных размерах и DPR. Увеличение разрешения PNG не устраняло этот способ формирования края.

Все растягиваемые поверхности активного интерфейса теперь рисуются одним CSS box: фон-градиент, непрерывный градиент рамки, border-radius и тень. Затронуты badge уровня, HUD цели/ходов, tray и карточки магнитов, подсказка обучения, кнопки, модальные окна, игровой и загрузочный progress. Изображения магнитов, логотип, пиктограммы и поле сохранены. Старые PNG рамок остаются в историческом наборе; CSS больше не использует их для плашек.
