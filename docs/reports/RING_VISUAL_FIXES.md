# Исправления визуализации — 2026-10-10

Пользователь сообщил о неверной ориентации стопок, несоответствии видимых слоёв перелетающим элементам и артефактах ассетов.

Причины: PNG кольца был ориентирован гранью вверх, а плитка — вершиной; PNG уже содержал боковую стенку. Наложение таких плоскостей скрывало границы настоящих элементов, а при перевороте показывало бумажную грань. Порядок отрисовки по рядам позволял плиткам закрывать низ стопки. В рамках оставались прямоугольные заплатки, в плитке — отдельные цветные пиксели.

Каждый элемент теперь имеет одну общую объёмную геометрию с настоящим отверстием и толщиной 0.15. Текстура верха берётся из мокапа без нижней боковины. Поворот вершиной вверх согласован с плиткой, переворот идёт вокруг центра, глубина определяет перекрытие колец. Высота соседних элементов отличается ровно на толщину кольца. Препятствие помещено на обычную плитку; raycast повторяет её видимый контур. PNG-рамки очищены с плавным переходом; углы и края модального окна согласованы. Правила, состав уровней и тайминг переноса не менялись.

Проверки:

- `pnpm check:full`: 135 тестов и production build.
- `GAME_BASE_URL=http://127.0.0.1:5174 node tools/browser-check.cjs`: desktop/mobile viewport, размещение/перетаскивание, pause/reset, все решения, победа/поражение, resize и освобождение.
- `node tools/raster-browser-check.cjs` с тем же GAME_BASE_URL: загрузка PNG, отказ/retry, обучение и адаптивность.
- `node tools/ring-browser-check.cjs` с тем же GAME_BASE_URL: 782 детерминированных WebGL-кадра всех решений, обычное/уменьшенное движение; сравнение ID всех неочищенных элементов с mesh, отсутствие дубликатов, число перелётов, физические позиции слоёв. Четыре общие геометрии остаются стабильными после прогрева. Один элемент может законно совершить несколько соседних перелётов — число событий переноса не равно числу уникальных колец.
- Визуально просмотрены снимки gameplay, pause и трёх фаз переворота; браузерные артефакты: `artifacts/raster-browser/`, `artifacts/ring-browser/`, `artifacts/three-browser/`.

Браузерные проверки используют Chromium и размеры экранов, а не физический телефон. Реальная мобильная производительность не измерялась. Это исправление конкретных причин артефактов; попиксельное совпадение всех адаптивных состояний с иллюстративными мокапами не заявляется.
