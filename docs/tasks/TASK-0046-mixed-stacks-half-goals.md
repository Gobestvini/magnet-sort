## 4. Требуемое поведение

Каждая вновь созданная стопка, при старте и после хода, содержит минимум2 цвета из текущих7. Предложение автора:2 или3 непрерывные цветовые группы снизу вверх, равновероятно; высота по-прежнему6 или12, делится поровну между группами:3+3/2+2+2 или6+6/4+4+4. Цвета групп выбираются без замещения внутри стопки, поэтому соседние группы точно различны. Это явно выбранный стартовый вариант, не требование пользователя о точном составе. Не независимо тасовать каждый unit в семь цветов — это дало бы нечитаемые одиночные слои и изменило баланс сильнее. Stable seeded порядок RNG: cell → height → groupCount → group colors; unit IDs снизу вверх последовательные, no Math.random/DOM. Спавн и replay одного seed воспроизводимы в новой политике; старые seed результаты изменятся, обозначить generator revision в spec/evidence. Goal=50*level.number для всех12; текст/aria/progress/terminal/звёзды/FTUE используют единый goal. Stars формулу не менять отдельно: пороги автоматически считаются от новой цели (уровень1:3<=5ходов,2<=9). НадGoal полоса clamp100%, count остаётся честным (48+6=54). Сохранять массу, immutable transitions, same-seed retry и invalid-action no draws.

Сохранить английский UI, доступные controls, pause/reset/hidden/dispose и reduced motion в применимой области.
