## 4. Требуемое поведение

Генерация через imagegen по background.png как style reference. Вернуть глубину, объёмные мягкие фаски, фиолетово-синие пятна света и крупный масштаб прежних плит. Исправить только неудачную геометрию: у каждого видимого полного хекса шесть согласованных граней, повторяемые плечи/вершины, общие рёбра без сломанных срезов и двойных канавок; обрезанные краем экрана фигуры допустимы. Сохранить мягкий проход света по канавкам по прежней .idle-grid-sweep: 11с и исходный профиль — baseline, не придумывать новую анимацию. Маску получить из того же финального источника геометрии; не генерировать независимо и не подгонять на глаз. Background/mask используют одинаковый cover/position/crop на portrait/landscape. Loading использует тот же новый фон; reduced/hidden/pause останавливают декоративное движение.

Сохранить английский UI, доступные controls, pause/reset/hidden/dispose и reduced motion в применимой области.
