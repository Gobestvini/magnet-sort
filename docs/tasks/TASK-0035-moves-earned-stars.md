## 4. Требуемое поведение

Новый run: 0 шагов. Только принятое размещение прибавляет 1; отмена/промах/выбор/пауза/подсказка не добавляют ход. Нулевой pull подчиняется принятому в TASK-0031 правилу. Звёзды считаются чистой функцией по goal/movesUsed/terminal с порогами окончательного GDD v0.4: на границе значение включительно; меньше шагов никогда не ухудшает результат. Победа даёт 1–3, поражение 0. Окно результата появляется после последнего начисления presentation; показывает шаги и реальное число полученных звёзд. Не показывать OUT OF MOVES при отсутствии лимита.

Сохранять английский пользовательский интерфейс, pause/reset/hidden/dispose, доступный tap/drag/keyboard и reduced motion в применимой области.
