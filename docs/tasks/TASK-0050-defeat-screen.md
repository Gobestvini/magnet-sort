## 4. Требуемое поведение

- Предложение композиции: затемнённое поле, компактная кремовая объёмная карточка, крупный фиолетовый лежащий магнит и несколько хексов как спокойная иллюстрация неудачи. Английские живые надписи BOARD FULL, No empty tiles left, MOVES, COLLECTED и Try again. Без победных звёзд/конфетти; поражение не изображать как успех.
- Сначала сгенерировать целевой макет через imagegen с текущими reference screenshots, затем отдельные пригодные PNG слои с alpha, без запечённой статистики и кнопки. Прозрачность проверить визуально; не подменять запрошенный арт CSS-плейсхолдером и не использовать один плоский скрин вместо UI.
- Статистика movesUsed, cleared/goal берётся из state; текст и кнопка — DOM. Единственное действие Try again вызывает существующий onReset и возвращает старт того же уровня. Никакого выдуманного Next level, стоимости или extra moves.
- Modal появляется только по terminal=lost после resolving; не мигает между фазами и не повторяет entry при rerender. Сохранить inert игрового поля, focus trap/возврат focus и keyboard activation. После reset исчезают overlay и stale callbacks.
- Адаптивно от 320px и в landscape: текст/кнопка не обрезаны, при необходимости доступен скролл. Reduced motion сохраняет короткий fade и статичный арт. Ошибки загрузки используют общий Retry; новые ассеты декодируются до ввода, пути работают под /magnet-sort/.
