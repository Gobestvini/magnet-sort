## 1. Цель и запрос пользователя

«Пусть уже на начальных уровнях будут стаки с разным количеством цветов». Сейчас первые три уровня содержат только одноцветные стопки. После изменения уже старт уровня 1 содержит одноцветные и двухцветные стопки; последующие партии этих уровней также могут выдавать оба вида. Это отдельное изменение контента, не расширение числа цветов палитры.

Предложение автора: 1 или 2 разных цвета в стопке, не вводить третий без необходимости; в пяти стартовых стопках гарантировать оба вида. Сохранить равные непрерывные цветовые группы.

## 4. Требуемое поведение

1. Уровни 1–3, каждый seed: среди 5 стартовых стопок есть хотя бы одна с 1 цветом и одна с 2. Расположение/цвета/высота остаются seeded; retry повторяет полное состояние. Предпочтительно задать bounded выбор числа групп при старте; не перегенерировать seed до удачного результата.
2. Последующие стопки на 1–3 используют [1,2] без требования разнообразия внутри партии из одной стопки. На серии фиксированных seed фактически встречаются оба варианта.
3. Стопки высоты 6/12: двухцветные группы 3+3/6+6, цвета разные, входят в палитру уровня, каждый цвет непрерывен. Не смешивать случайно каждый слой. Начальная палитра остаётся из трёх цветов.
4. Стопка с чужим верхом не выдаёт магнит по скрытому нижнему цвету; очередь после спавна отражает открытые верхи, без дублей. Unit IDs, RNG purity/determinism, immutable apply, conservation и пустое поле fallback сохранены.
5. Старт и последующий спавн визуально показывают разные слои; цифра показывает только верхнюю непрерывную группу. Не усложнять остальные уровни попутно.
