## 1. Цель и запрос пользователя

Заменить неудачно выглядящую анимацию над полем: круговые волны сходятся к центру магнита и видны только через маски бортиков ячеек двух ближайших колец.

Исходный запрос: «мне нужно переделать анимацию когда магнит над полем, сейчас она стремно выглядит, нужно у каждой ячейки создать маску на ее бордер, и когда магнит над полем включается маски над ячейками на который действует магнит два ближайших крга и кать по этой маске анимацию кргов которые сходятся в центр магнита».

Сейчас: все бортики первого кольца одновременно пульсируют, затем все бортики второго. После: несколько концентрических волн движутся снаружи внутрь; на бортиках видны движущиеся дуги их пересечения. Движение проходит внешнее кольцо, затем внутреннее. Центры ячеек и пространство между ними не подсвечиваются.

## 4. Требуемое поведение

1. Каждая плитка имеет переиспользуемую маску своей видимой полосы бортика. Маска исключает углубление и внешнее пространство, совпадает со всеми шестью гранями, учитывает текущие width/height/offset и наклон проекции. Общая геометрия допустима; отдельная текстура на каждую клетку не обязательна.
2. Над допустимой candidate-клеткой включены маски только существующих ячеек distance=1/2. Центральная клетка не входит. На краю поля список обрезается по state.cells. Неподходящая клетка, отсутствие выбранного магнита и terminal не показывают preview.
3. Все активные маски показывают части ОДНОГО общего радиального поля волн с центром в candidate-клетке, цветом выбранного магнита. Это круги в плоскости поля с естественной проекцией камеры, не отдельные концентрические круги вокруг каждой соседней клетки.
4. Радиус каждой волны монотонно уменьшается. Видимый акцент идёт от второго кольца к первому и исчезает у центра; повтор начинается за внешней границей активных бортиков, без заметного скачка яркости. Запрещено заменять это попеременным перекрашиванием целых колец.
5. Предложение автора для стартовой настройки: три равномерно сдвинутые по фазе волны, полный проход около 2.4 s, мягкие края полосы и fade на входе/выходе. Значения можно настроить по браузерным кадрам без изменения цели. Толщина должна показывать движение дуги внутри бортика, а не постоянно заливать оба кольца.
6. Над неподвижным магнитом и при keyboard candidate движение продолжается через существующий runtime RAF. При смене cell/color центр и цвет обновляются сразу, без следа старой зоны.
7. Порядок отрисовки сохраняет видимый объём: маска не окрашивает фишки, цифры или X. Проверить частичное перекрытие бортика стопкой, а не поднимать все эффекты над всей сценой.
8. Reduced motion: статичный умеренный tint обоих колец (.45 допустимо), без сходящихся волн и без постоянного RAF для неподвижного preview. Pause/hidden/cancel/выход за поле/reset/смена уровня/dispose убирают preview по действующему lifecycle. При старте рабочей timeline preview передаёт управление её текущим эффектам.
9. Геометрия, маски, материалы и временные векторы создаются при инициализации/смене поля, а не каждый кадр или pointermove. Один владелец ресурсов board, общий sampled clock; нет второго RAF/таймеров, постобработки или изменений shared tile materials.
