## 4. Требуемое поведение

Уточнение пользователя 2026-10-12: внутри ячейки не должно быть нарисовано самого магнита. Магнитное состояние показывают только бортики: цвет выбранного магнита, светящийся контур и анимация энергии по шести рёбрам. Центр остаётся обычным пустым углублением. U-образный символ/инкрустация и отдельный лежащий магнит после активации запрещены; U-спрайт допустим только в tray, drag и hover-preview.

Повторное уточнение 2026-10-12: остальные шесть вариантов нравятся пользователю; фиолетовый должен совпадать с ними по оформлению. Вся внешняя рамка и нижняя стенка фиолетовые, без кремовой наружной кромки. Только центральное пустое углубление остаётся кремовым. Фиолетовый вариант перегенерирован на основе синего с сохранением его геометрии.

Состояния view: ordinary → activation → magnetic-active → deactivation → ordinary. Ячейка действительно меняет рисунок/материал и выразительность контура, а не только получает лежащую U-иконку. Сгенерировать новые клетки в той же камере, с совпадающими внешним контуром/якорем/внутренней посадкой. Прилёт drag плавно переходит в короткий акцент/pulse/crossfade (предложение автора); приём элементов начинается после активации. Оставшиеся хексы не исчезают при обратном превращении. Hover — preview, не фактическая активация; invalid/cancel не запускают её. Reduced motion — короткая смена состояния. Reset/смена уровня/context retry не оставляют магнитную текстуру; общий sampled clock, без второго RAF.

Сохранять английский пользовательский интерфейс, pause/reset/hidden/dispose, доступный tap/drag/keyboard и reduced motion в применимой области.
