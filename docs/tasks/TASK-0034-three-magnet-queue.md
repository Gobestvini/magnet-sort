## 4. Требуемое поведение

Согласовано: запрет повторов относится к трём видимым цветам, не к истории партии. После успешного срабатывания удалить использованный слот, сохранить относительный порядок остальных двух, добавить один из цветов, которых нет среди этих двух. Только что использованный цвет снова разрешён; равномерный выбор из допустимых цветов через RNG state. Все три видимых магнита доступны для выбора, включая средний/последний. Во время resolve и сдвига повторный ввод запрещён. Невалидный drop/cancel возвращает тот же магнит, не расходует слот и RNG. Следующий цвет виден после действия; стабильные ID слотов не должны прыгать между drag и DOM. Tap и keyboard сохраняются.

Сохранять английский пользовательский интерфейс, pause/reset/hidden/dispose, доступный tap/drag/keyboard и reduced motion в применимой области.

## 5. План для исполнителя

1. Сверить новый model state, seed и стадии TASK-0033.
2. Реализовать pure операции начальной тройки и consume/refill; при необходимости добавить ID slot в action с повторной валидацией модели.
3. Перестроить tray на ровно три слота без ветки первого уровня/all colors.
4. На общем lifecycle выполнить короткий сдвиг двух оставшихся и появление нового; reduced motion без перемещения.
5. Согласовать selected/drag home после отмены, расхода и reset.

## 6. Критерии готовности

- [ ] На протяжении 1000 детерминированных consume/refill тройка остаётся длиной 3 без повторов.
- [ ] Удаление любого из трёх слотов сохраняет порядок остальных, RNG не меняется при отмене.
- [ ] В браузере нет четвёртого доступного магнита; повторный drop во время resolve не принимается.
- [ ] Reset восстанавливает стартовую тройку того же seed, pause/hidden не расходуют её.
