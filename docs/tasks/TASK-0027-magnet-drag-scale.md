## 4. Требуемое поведение

Предложение автора: targetSize равен board.magnetScreenSize() при нахождении указателя над любой плиткой поля, включая занятую; вне поля — исходному размеру захвата. Зону определять по фактическому clientX/clientY указателя и board.pick, независимо от пружинного отставания картинки. Во время drag менять масштаб за 160–220 мс с dt-зависимым сглаживанием без overshoot; при уходе из поля мягко увеличивать обратно. Не уменьшать повторно при каждом pointermove.
Хранить предыдущий/текущий размер для render(alpha), обеспечить одинаковый переход при 30/60/120/144 FPS. Масштаб вокруг центра; смещение над пальцем и raycast сохранить. На допустимом drop довести размер до проекции до скрытия DOM и появления board-магнита, допустимое расхождение ширины 2 CSS px. На недопустимом drop вернуть в home с исходным размером без расхода хода. Учесть drag, начатый с поля после tap-выбора.
Сохранить tap-to-place, keyboard, pointer capture, защиту от второго pointer. cancel/blur/hidden/pause/reset/resize/dispose удаляют drag и scale state. Reduced motion сразу устанавливает целевой размер без пружинного колебания. Размер вычислять из текущего layout в CSS px, не из DPR.
