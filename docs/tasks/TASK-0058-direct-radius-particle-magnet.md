## 1. Цель и запрос пользователя

Магнит забирает подходящие верхние хексы со всех обычных клеток двух полных колец непосредственно к себе. Подсветки клеток-источников нет; при удержании магнита над полем из окружающих клеток летят несколько частиц по высоким параболам.

Исходный запрос 2026-10-16: «магнит должен работать на все ячейки в пределах двух колец; пусть они перелетают сразу к магниту; не нравится подсветка на ячейки от которой идут хексы, убери её; добавим партиклов… когда магнит над полем… от ячеек к магниту… несколько с каждой… по большой параболе». Ранние смешанные стопки — TASK-0059. Пользователь также поручил выполнить задачи после создания.

## 4. Требуемое поведение

1. Источник — существующая обычная клетка с `1 <= hexDistance(source,target) <= 2`. Внутри полного поля это 18 позиций, включая непрямые позиции второго кольца. Край обрезает область. X не источник; X и чужой верх между источником и магнитом не блокируют прямой перелёт. Дистанция 3 не действует.
2. Только непрерывная верхняя группа выбранного цвета; чужой верх не позволяет извлекать скрытый цвет. У всех перемещённых ID ровно одно `unitMoved`, `from` исходная клетка, `to` магнит; deterministic порядок distance/row/col, внутри группы сверху вниз. Никаких временных стопок/посадок на промежуточных клетках. «Сразу» здесь означает напрямую, поэлементный короткий stagger можно сохранить.
3. Сохранить immutable вход, IDs/порядок units, clearSize=6, остаток у магнита, начисление при HUD arrival и conservation `spawnedUnits = cleared + remainingUnits`. Preview соответствует actual plan без RNG. Invalid action/terminal по прежнему контракту.
4. Убрать preview rim waves и рабочие marks/контуры у всех соседних клеток, включая reduced motion. Оформление/бортик самого активного магнита и invalid placement feedback сохранить. Никакого обесцвечивания PNG/мигания соседей.
5. Предложение автора для неоднозначного «от ячеек»: декоративные частицы из всех обычных клеток двух колец, включая пустые/чужого цвета; X исключить. Это показывает геометрическую зону, а реальное притяжение по-прежнему только по верхнему цвету. По 3 частицы на клетку, fixed pool до 54; не обрезать последние клетки лимитом прежних 48.
6. Частицы идут source→magnet по дуге с нулевым подъёмом в концах и заметно высоким пиком (начальная настройка 1.1 world unit). Разные фазы, цвет выбранного магнита; видны без отпускания и при неподвижном drag/keyboard candidate. Позиция прибытия совпадает с magnetAnchor, ни движения от магнита наружу, ни случайного RNG модели. После placement можно продолжить те же дуги до деактивации.
7. Над невалидной/занятой/X/внешней целью эффекта нет. Смена кандидата/цвета обновляет источник/приёмник без хвоста старой цели. Pause/hidden/cancel/reset/resize/dispose гасят preview; reduced motion отключает движущиеся частицы и не возвращает подсветку соседей. Timeline продолжает штатную паузу/возобновление.
8. Общие geometry/material и один runtime RAF; нет роста ресурсов на 20 повторных циклах. Частицы не меняют модель/счётчик и не перехватывают ввод.
