## 4. Требуемое поведение

Предложение автора «мягкое раскрытие»: panel за 280–340 мс проходит opacity 0→1, translateY(18px)→0 и scale .92→1.015→1; последние 60–80 мс — мягкое успокоение. Backdrop проявляется за 180–220 мс, без смены текущего оформления victory. Только transform/opacity, без покадрового layout и тяжёлых фильтров. Кнопки доступны сразу, без искусственной блокировки ввода до animationend.
Каждое реальное открытие проигрывается один раз; обычный Preact rerender не перезапускает. При переходе одного типа попапа в другой не наследовать незавершённую фазу. Быстрые pause/resume/restart/next не оставляют невидимых overlay. Focus trap, Escape для pause, inert фона и возврат фокуса сохранить. Launch error не должен ждать готовности Three/assets для появления и доступности Retry.
Учитывать системный prefers-reduced-motion и программный reduced из runtime: в этом режиме нет translate/scale/overshoot, допускается opacity не дольше 80 мс. Нельзя полагаться на существующий CSS transition:none для новых keyframes. При hidden/возврате не проигрывать вход заново. В portrait/landscape и низком окне кнопки остаются видимыми либо доступны скроллом.
Для реализации выбрать локальные create-task/game-quality и практики playbook; специализированный сетевой навык нужен только при реальном пробеле. Не подключать Figma, генерацию изображений или animation library ради этой CSS-задачи.
