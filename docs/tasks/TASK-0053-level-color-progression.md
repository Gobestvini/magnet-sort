Один чистый helper levelPalette(number) возвращает стабильную палитру. Нельзя удалить остальные COLORS или ассеты. Стартовые и новые стопки, стартовые и новые магниты используют только палитру уровня. Не расширять schema level без необходимости: number уже есть в state. Группы стопки пока остаются 2–3 и никогда не превышают размер палитры.
Сохранить три уникальных магнита на этом этапе, RNG/state ownership, retry по seed, immutable rejected action, unit IDs, массу, goal=50*N, звёзды, 12 уровней и старые v3 fixtures. Изменение результатов старых seed из-за новой палитры допустимо, повторяемость новой версии обязательна.
