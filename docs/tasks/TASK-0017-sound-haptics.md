## 4. Требуемое поведение

- Move click, magnetic whoosh, stack lock и clear chime привязать к ordered events; звук не дублируется при replay/reset callbacks.
- Начинать AudioContext после пользовательского жеста; mute сохраняется, hidden/pause останавливает звук. Недоступный/запрещённый audio не ломает игру.
- Haptics только capability-based и отключаемы; отсутствие API покрывается визуальным feedback. Цвет, звук и вибрация не единственные признаки победы/ошибки.
- Использовать собственные синтезированные звуки либо ассеты с проверенным правом использования; записать источник/лицензию/вес. Освобождать nodes/listeners при dispose; ASMR исключён.
