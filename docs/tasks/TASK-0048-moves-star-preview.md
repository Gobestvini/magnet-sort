## 1. Цель и запрос пользователя

Референс пользователя: обрезка HUD с кремовой плашкой MOVES, фиолетовыми буквами и синим фоном. ## 4. Требуемое поведение

1. Сгенерировать новый арт компактной золотой звезды с мягким бликом и объёмом в стиле существующих кремовых/фиолетовых панелей. Настоящая прозрачность, без прямоугольной подложки, букв и чисел. Звёзды читаемы в малом размере; не заменять генерацию emoji/CSS-звездой или запечённым скриншотом HUD.
2. Три звезды стоят над MOVES, визуально принадлежат плашке. Уточнение пользователя при реализации: использовать уже свободное место, не поднимать/сдвигать лого и другие элементы; звёзды теснее и по небольшой дуге (средняя выше боковых). Абсолютный ряд не добавляет высоты HUD. Не перекрывать LEVEL, паузу, цель/прогресс или поле, не уменьшать доступность управления. Погасшие звёзды сохраняют форму, размер и положение; различаются яркостью/насыщенностью, без сдвига вёрстки.
3. В начале уровня горят 3. Для `goal=50`: moves 0–5 → 3, 6–9 → 2, 10+ → 1. Для `goal=100`: 0–9 → 3, 10–17 → 2, 18+ → 1. Для `goal=600`: 0–50 → 3, 51–100 → 2, 101+ → 1. Гасить справа налево только после превышения включительной границы.
4. Расчёт прогноза и победной награды использует единую логику порогов. Live `state.stars` равен 0 и не подходит для прогноза. Не изменять его ради HUD. Прогноз означает награду при победе сейчас; проигрыш по-прежнему даёт 0 фактически заработанных звёзд.
5. Обновлять звёзды синхронно с видимым счётчиком MOVES при принятом ходе, включая ход без притяжения. Hover/drag, отмена и недопустимая постановка прогноз не меняют. Пауза сохраняет состояние. Retry/новый уровень сбрасывают прогноз к 3.
6. Погасание короткое и плавное, без мигания/постоянной анимации; `prefers-reduced-motion` отключает переход. Новые декоративные элементы не перехватывают pointer/keyboard input. Для screen reader дать английское имя, например `Potential stars: 2 of 3`, декоративным PNG пустой alt; не озвучивать их как гарантированную награду.
7. Новые PNG проходят штатную загрузку/error/retry. Корректны под `/magnet-sort/`. Не создавать отдельный animation loop или ресурс на каждый ход.
