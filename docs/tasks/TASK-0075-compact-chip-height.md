## 4. Требуемое поведение

Все 7 цветов имеют одинаковый меньший вертикальный шаг. В стопках 1/6/8/9 число фишек соответствует модели, смешанные границы видимы. Нижняя фишка остаётся в углублении, footprint не сужается. Перелёт садится непрерывно на новую высоту; цифры и начало полёта в HUD совпадают с реальной верхушкой. Упаковка не проводит верхние элементы через нижние. Pause/resume/reset/reduced/resize сохраняются. Новые таймеры/RAF или ресурсы на кадр не нужны.
