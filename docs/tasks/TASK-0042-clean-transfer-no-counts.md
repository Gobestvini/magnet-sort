Применять game-quality; для генерации PNG — imagegen; для объёмного контекста — ai-economy.

## 4. Требуемое поведение

Каждый реальный хекс переносится по соседнему ребру непрерывно, без чёрных треугольников/прямоугольников/мигания/прохода через непрозрачный соседний слой. Сохранить ощущение поштучного перекладывания с объёмом и корректной посадкой; иной профиль поворота допустим, если текущий face/backing подход создаёт дефект. Зафиксировать причину (alpha/depth/renderOrder/back face/pivot/PNG) до решения. Цифры у source/destination участвующих в перебросе скрыты на всём интервале движения, включая промежутки stagger; не мелькают на коротких посадках. У неподвижных неучаствующих стопок цифры допустимы. Перед clear один читаемый badge показывает количество именно зачтённых хексов данной группы, не весь смешанный стек; предложенный акцент 200–300мс, reduced короче. Во время packing/полёта в HUD цифры скрыты. ID/count/события модели неизменны.

Сохранять английский пользовательский интерфейс, pause/reset/hidden/dispose, доступный tap/drag/keyboard и reduced motion в применимой области.
