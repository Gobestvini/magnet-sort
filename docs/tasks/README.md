# Самостоятельные задания

`INDEX.md` — очередь, `TEMPLATE.md` — формат, `TASK-NNNN-short-name.md` — одна проверяемая цель. Создавай задачи по запросу; история прошлой игры сюда не переносится. Карту кода смотри в `../PROJECT.md`.

Актуальная спецификация Magnet Sort — `../design/GDD_V0.4.md` и `../design/THREE_RENDERING.md`: Three.js, Preact, seeded accumulation rulesVersion 4. Исторические задачи TASK-0001–0024 описывают прежний PixiJS MVP; их done не означает приёмку новой версии. TASK-0024 blocked и заменена новым направлением в прежних границах; не запускать её как следующую в очереди v4. TASK-0025/0042/0057 закрыты по пользовательской приёмке 2026-10-25. Актуальную очередь и зависимости смотреть в INDEX и самих задачах: 0071 (доска дня), 0072 (вызов другу), 0076 (лидерборды кампании и дня); 0073 отменена. Перед выполнением сверять код v4 и `src/prototype/*`, не переносить старые контракты mass/merge и renderer автоматически.

Статусы: draft → ready → in-progress → review/done; blocked означает необходимое решение или зависимость. cancelled — отменена пользователем, её требования не объявляются выполненными; при замене указать новую задачу. Файл задачи — источник истины, INDEX обновляется вместе с ним. review нужен при предусмотренной отдельной проверке. done допустим после всех обязательных проверок либо явно записанной пользовательской приёмки оставшихся критериев; вид подтверждения и ограничения сохранять. Нерешённый важный вопрос не допускает ready.

Для подготовки применяй `.agents/skills/create-task/SKILL.md`. Проверь код, ревизию и команды; различай требования пользователя, факты и предположения. Задача понятна без истории чата. Для небольшой правки сохраняй только полезные детали; длина не является критерием качества.

Исполнитель читает задание целиком, проверяет актуальность и зависимости, меняет только указанную область, выполняет проверки и заполняет секцию 10. Релевантные unit tests проверяют логику; сборка проверяет интеграцию; интерфейс/ощущение игры проверяются в браузере руками и сценариями. Не ослабляй критерии ради экономии токенов.

```text
Выполни docs/tasks/TASK-NNNN-short-name.md. Прочитай AGENTS.md и задачу целиком, проверь актуальность и зависимости, внеси изменения в указанных границах. Выполни обязательные проверки, заполни отчёт, обнови статус и INDEX.
```

Не запускай исполнителей одновременно на одних файлах без согласования. Подготовка задания не запускает другую модель и не создаёт чат.
