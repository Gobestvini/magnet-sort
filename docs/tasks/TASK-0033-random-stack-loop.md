## 4. Требуемое поведение

Реализовать окончательный контракт TASK-0031. Детерминированный RNG хранится в state; модель не читает Math.random/Date.now/DOM, seed задаёт runtime при новом запуске. Retry повторяет seed исходного run, новый уровень получает новый seed. Уникальные ID хексов не переиспользуются; инвариант spawned = board + cleared (с учётом исходных элементов). Spawn только в допустимые свободные клетки, никогда в blocker или занятую клетку; bounded выбор без бесконечного поиска. Отклонённый placement не меняет RNG, шаги, поле. Спавн не начинается во время drag/pause/resolve и после победы. Победа по goal, пустое поле до достижения goal не является победой. Не сохранять прежний лимит moves. UI использует goal; отображаемое начисление следует прибытию по timeline.

Сохранять английский пользовательский интерфейс, pause/reset/hidden/dispose, доступный tap/drag/keyboard и reduced motion в применимой области.
