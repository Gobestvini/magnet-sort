## 4. Требуемое поведение

Данные каждого уровня: стабильный id/номер для навигации и массив blockers; нет stacks/moves/magnets/solution/отдельного goal/seed в уровне. Общая форма поля, параметры генерации, пороги и цель 100*N принадлежат общей конфигурации/правилам. Предложение автора: 1–4 креста на поле, разные позиции у 12 уровней; валидатор отвергает дубликаты/вне поля и не допускает полностью закрытого поля. Проверить связность/доступное размещение и отсутствие явно непроходимых начальных состояний на фиксированных seeds. FTUE обучает реальной очереди и цели; authored solution hint для v4 заменить безопасным скрытием без ложного обещания решения. Случайное поле не выдавать за доказанно решённую старую головоломку.

Сохранять английский пользовательский интерфейс, pause/reset/hidden/dispose, доступный tap/drag/keyboard и reduced motion в применимой области.
