## 1. Цель и запрос пользователя

«Выделение ячеек при переносе магнита не нравится… может тинтом подсвечивать ячейки через моргания… все ячейки по кругу от ячейки с магнитом на два поля… попробуй сгенерить, как это выглядит, и я скажу, норм или нет».

Наблюдаемый результат после оценки: при drag видна мягко пульсирующая заливка поверхностей всех ячеек вокруг цели в радиусе 2, вместо текущих контуров/искр preview. Макет уже подготовлен: `docs/design/tint-preview-v1/concept.png`, промпт/ограничения в `PROMPT.md`. SOFT и BRIGHT — две фазы одной пульсации, не разные режимы. Это статическая художественная проба; пока не проверена пользователем и не перенесена в игру.

## 4. Требуемое поведение после согласования

- Предлагаемое толкование «по кругу»: все клетки state.cells с 1<=hexDistance(center, cell)<=2 — до 18 соседей, плюс отдельно выделенный center. Края обрезаются границами поля. Это геометрическая зона proximity, не обещание pull из каждой клетки.
- Центр должен быть legal пустой клеткой. Кресты исключить из tint; занятые стопками клетки подсветить по поверхности под фишками, не перекрашивая сами chips. Геометрический радиус не строить BFS в обход препятствий. Если пользователь хочет иную маску/изменение pull, сначала обновить задание.
- Сохранять исходный объём/фаску/бортик PNG-ячейки. Тинт цветом выбранного магнита, прозрачность ориентировочно 0.15–0.35, синусоидальная мягкая пульсация с периодом 1.2s; центр немного сильнее. Это предложенные настройки, окончательно сверить с оценкой. Не полное включение/выключение и не резкие вспышки.
- Убрать старые drag-контуры/частицы/лишний halo, конкурирующие с заливкой; actual work waves/particles после размещения сохранить. Неверная/занятая цель и указатель вне поля не показывают зону. Смена клетки/цвета убирает старый tint и обновляет новый без следов.
- Preview доступен при текущих drag, tap-to-place и keyboard candidate согласно модели ввода; не добавлять hover-зону без выбранного магнита. Reduced motion — постоянный тинт умеренной яркости без пульсации.
- Время берётся из app runtime; pause/hidden замораживают/скрывают корректно, resume без скачка. Cancel, release, lost capture, reset, blur/resize/dispose и terminal убирают preview. Не мутировать общий материал так, чтобы окрасились клетки вне маски. Ресурсы фиксированы/переиспользуются и освобождаются board.
