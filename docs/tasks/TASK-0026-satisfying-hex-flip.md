## 4. Требуемое поведение

Предложение автора, а не измеренные параметры референса: один перенос 240–300 мс, запуск следующего через 90–120 мс; небольшое перекрытие допустимо, но фишки не движутся слитным пакетом. Фазы: короткий подъём верхнего элемента, один переворот на 180° через поперечную направлению ось, замедление перед посадкой и небольшой settle до 40 мс. Не добавлять ожидание на каждый кадр или таймер на фишку.
PNG имеет нарисованную переднюю стенку: простой конечный поворот на PI может показать пустую изнанку или инвертировать объём. Обеспечить обе читаемые стороны средствами общей backing geometry/material и вернуть корректную ориентацию покоя без видимого скачка. Равноценная кинематика допустима, если сохраняется ощущение одного переворота, а не полного воздушного сальто.
Каждый unitMoved отображает ровно один ID; fromIndex/toIndex задают реальные высоты. Верх стопки открывается последовательно; приземлившийся ID участвует в счётчике только после посадки. Проверить все шесть направлений и разные высоты, включая 20 элементов. Не допускать прохода через стоящие фишки, пропажи граней, обрезания painter order и скачка на границе batch/clear.
Reduced motion: короткое перемещение без переворота и большой дуги. Pause/hidden останавливают время; reset/смена уровня/dispose убирают незавершённый перенос.
