## 4. Требуемое поведение

Ровно 7 стабильных цветовых ID. Предложение для проб: добавить тёплый жёлтый, зелёный, бирюзовый и розовый; окончательные hex выбрать по контактному листу на текущем фоне, отделив blue/turquoise и coral/pink по тону и яркости. Сгенерировать полный согласованный набор 7 магнитов; для новых 4 цветов нужны полноценные chip PNG с той же камерой, посадкой и фаской. Не ограничиваться CSS hue-rotate. Прозрачный фон без чёрной каймы/запечённой клетки, единый визуальный масштаб; у магнитов нет символов. Включить новые текстуры в load/error/retry/dispose и BASE_URL.

Сохранять английский пользовательский интерфейс, pause/reset/hidden/dispose, доступный tap/drag/keyboard и reduced motion в применимой области.
