## 4. Требуемое поведение

Перед ready дополнить этот раздел по наблюдениям. Минимальные неизменяемые контракты:

- Resolve отображает прежние events по порядку wave; конечный state и canonical replay полностью совпадают до/после.
- Presentation lift/layer landing не мутируют token.cell/mass в модели и не открывают ввод до завершения.
- Reduced motion сокращает декоративное движение, сохраняя причины хода и порядок cues. Pause/reset/hidden/retry/dispose отменяют всё, не оставляют промежуточный ghost или lock.
- Clear раскрывает пустую клетку нашей игры; не показывать скрытый нижний цвет, которого нет в state.
- Tutorial обучает магниту с понятной стрелкой tray→legal cell; инструкция/skip остаются доступными, стрелка не закрывает цель.
- Все цифры timing/easing/overshoot/result-layout и звуковой профиль добавляются после реального наблюдения. Предложения для адаптации отмечаются отдельно от измерений референса.
