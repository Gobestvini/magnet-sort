## 4. Требуемое поведение

Предложение автора: уровни 1–3 — одна одноцветная группа; 4–6 — 1 или 2 группы; 7–12 — 2 или 3 группы. Допустимое число групп выбирается seeded из стабильного списка; для одного допустимого варианта RNG не расходуется. Каждый выбранный цвет группы различен, принадлежит палитре уровня. Группы непрерывны и равны по длине; 6 и 12 делятся на 1/2/3.
Одинаковая политика для initial и turn spawn. Моноцветность не означает фиксированную высоту, дополнительную очистку или auto-win. После переносов стопки могут иметь иной состав — ограничения только для вновь созданных стопок. Сохранить top-group счётчик UI, IDs, conservation, immutable transitions и tops queue. Точные диапазоны — предложение автора для дальнейшей проверки сложности, не результат playtest.
