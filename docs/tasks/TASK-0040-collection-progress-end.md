## 4. Требуемое поведение

Предложенная трактовка «конец линии»: правый конец заполненной части, а не центр числа и не всегда правый край пустой дорожки. Получать целевую точку из актуального rect track и численного displayedProgress: x=left+width*clamp(progress,0,1), y=centerY; на 0/100% учитывать радиус и отступ так, чтобы эффект оставался внутри контура. Не полагаться на key:state.turn и CSS transition width при измерении. Во время партии линия растёт по прибытию; активный полёт нацелен на актуальную кромку без заметного скачка. Пульс/искры локализованы у кромки, без трансформации всей полосы, меняющей rect. Начисление по ID ровно один раз, reduced motion без экранного перелёта. Счётчик остаётся текстом прогресса.

Сохранять английский пользовательский интерфейс, pause/reset/hidden/dispose, доступный tap/drag/keyboard и reduced motion в применимой области.
