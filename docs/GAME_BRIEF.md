# Magnet Sort — паспорт игрового цикла v4

Актуально 2026-10-12. Правила: [GDD v0.4](design/GDD_V0.4.md); rendering/lifecycle: [THREE_RENDERING](design/THREE_RENDERING.md); результаты: [V4_REWORK](reports/V4_REWORK.md).

- Игрок выбирает один из трёх магнитов и размещает его на пустой hex-клетке; tap/drag/keyboard. Стопки вручную не двигаются.
- Цель уровня N — собрать 50*N хексов, а не очистить стартовое поле. Стопки случайно появляются при старте и после принятого размещения. Spawn — до 2 стопок по 6 или 12; старт — 7. Выбор клеток/цветов seeded, retry повторяет seed. Таймерного спавна нет.
- Очередь — три разных цвета из семи. После хода выбранный расходуется, оставшиеся сдвигаются, добавляется допустимый случайный цвет; использованный может вернуться.
- Магнит временно активирует цветные бортики клетки. Центр остаётся пустым кремовым, символ магнита не рисуется. После работы бортики возвращаются. X — отдельная цельная клетка, препятствие для spawn/placement/маршрута.
- Matching верхние элементы перемещаются по одному через соседние рёбра. Новый профиль — короткий rocking hop с объёмом и непрерывной посадкой; группы по 6 очищаются только у магнита.
- Цифры участвующих клеток скрыты при переносе; перед сбором коротко видно 6 зачтённых хексов. Они летят в край заполненной полосы, счётчик растёт по прибытии.
- Шаги идут вверх с нуля, отмена/промах не расходуют ход. Победа — goal; поражение — нет пустой клетки. 3/2/1 звезды зависят от числа принятых ходов по общим порогам. Числа спавна и звёзд — стартовый баланс автора, не исследованная оптимальность.
- 12 уровней хранят лишь identity/number/blockers. Старые authored v3 данные и legacy MVP сохранены как регрессии; случайные поля не объявляются доказанными старым solver.
- Three.js 0.186.1 + Preact, английский интерфейс, RGBA PNG assets, единый SVG backdrop/idle, один app-owned RAF/fixed step, immutable model/events, reduced motion, pause/hidden/resize/reset/dispose.
- За границами запроса: перенос legacy save/social/ads/audio, монетизация, physics engine, свободная камера, Telegram. Коммит/push/Pages выполняются по постоянному разрешению AGENTS.md.

## Устройства и evidence

Desktop Chromium, mobile/landscape viewport — browser surrogate; физический телефон не проверялся. Цель p95 <16.7мс на Pixel 6a / Android 13+ / Chrome остаётся гипотезой. Бюджет PNG/texture memory не утверждён; новые оригиналы повышают transfer/texture memory, реальные измерения телефона ещё нужны. Shared resources, 20 reset cycles и отсутствие роста geometries проверяются отдельно от FPS.

Исторический паспорт v3 доступен в Git до этого перехода.
