- Игрок выбирает один из трёх магнитов и размещает его на пустой hex-клетке; tap/drag/keyboard. Стопки вручную не двигаются.
- Цель уровня N — собрать 50*N хексов, а не очистить стартовое поле. Стопки случайно появляются при старте и после принятого размещения. Spawn — 1 стопка на ходах 1–5×N², 2 на 5×N²+1–10×N², 3 с 10×N²+1 (N=номер уровня); по 6 или 10 хексов, старт — 5. Последний свободный слот не резервируется. Выбор клеток/цветов seeded, retry повторяет seed. Таймерного спавна нет.
- Палитра уровней 1–3/4–6/7–9/10–11/12: 3/4/5/6/7 цветов. Новые стопки: 1–2 группы на 1–6, 2 на 7–12; на каждом старте 1–3 есть оба варианта; группы равные, непрерывные, без повторных цветов. Очередь — до трёх открытых верхних цветов после спавна; retained цвета сохраняются только пока открыты. При одном/двух верхних цветах виден один/два магнита. Пустое поле до цели допускает fallback на палитру уровня.
- Магнит временно активирует цветные бортики клетки. Центр остаётся пустым кремовым, символ магнита не рисуется. После работы бортики возвращаются. X — отдельная цельная клетка, препятствие для spawn/placement, но не для прямого перелёта над ним.
- Matching верхние элементы из всего hex-радиуса типа 1/2 перемещаются по одному прямо к магниту без промежуточной посадки. Новый профиль — короткий rocking hop с объёмом и непрерывной посадкой; группы по 10 очищаются только у магнита.
- Цифры участвующих клеток скрыты при переносе; перед сбором коротко видно 10 зачтённых хексов. Они летят в край заполненной полосы, счётчик растёт по прибытии.
- Шаги идут вверх с нуля, отмена/промах не расходуют ход. Победа — goal; поражение — нет пустой клетки. 3/2/1 звезды зависят от числа принятых ходов по общим порогам. Числа спавна и звёзд — стартовый баланс автора, не исследованная оптимальность.
- 12 уровней хранят лишь identity/number/blockers. Старые authored v3 данные и legacy MVP сохранены как регрессии; случайные поля не объявляются доказанными старым solver.
- Three.js 0.186.1 + Preact, английский интерфейс, RGBA PNG assets, единый SVG backdrop/idle, один app-owned RAF/fixed step, immutable model/events, reduced motion, pause/hidden/resize/reset/dispose.

## Устройства и evidence

Desktop Chromium, mobile/landscape viewport — browser surrogate; физический телефон не проверялся. Цель p95 <16.7мс на Pixel 6a / Android 13+ / Chrome остаётся гипотезой. Бюджет PNG/texture memory не утверждён; новые оригиналы повышают transfer/texture memory, реальные измерения телефона ещё нужны. Shared resources, 20 reset cycles и отсутствие роста geometries проверяются отдельно от FPS.

Исторический паспорт v3 доступен в Git до этого перехода.


Уточнение темпа 2026-10-13: поздние уровни сохраняют замедление, но без долгого ожидания ресурсов. Начало — 5 стопок; интервал уровней 1–6/7–9/10–12: 1/2/3 хода. Между партиями RNG спавна не расходуется; размер партии 1 до 5*N*N ходов, 2 до 10*N*N, затем 3. Победа проверяется до партии; lost проверяется и на ходах без партии. С 2026-10-16 притяжение прямое во всём hex-радиусе 2, X/чужой верх других клеток не мешают. По уточнению пользователя 2026-10-16 восстановлен preview через маски бортиков двух колец (включая X), вместе с небольшими частицами из обычных клеток (по 3, до 54). Скорость, фаза, высота и боковой изгиб частиц различаются без RNG модели. Во время всей timeline хода частицы выключены; reduced сохраняет статичные маски без частиц. Проверены 600 seeded побед greedy и 36 replays; это не гарантия всех seed и не субъективный тест новичков.
