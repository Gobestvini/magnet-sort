# Startup, asset graph и отдельная статика

2026-10-18, перенос из White Tower на Three.js 0.186.1 / Vite 7.1.9.

- Признак: при отдельном shell старый browser smoke видит отсутствие `.loading-screen` ещё до исполнения entry. Причина: HTML-прелоадер появился раньше Preact. Способ: ждать удаления `body.dataset.startup` вместе с завершением внутренней загрузки; не считать отсутствие игрового оверлея доказательством готовности. Проверка: production browser flow и отдельный loader tool. Ограничение: это browser surrogate, не физический телефон.
- Признак: весь public (около 43 МБ) попадал в build, а dynamic PNG URL не входили в asset graph. Способ: общий allowlist `src/art/catalog.js`, build-transform resolver в статические `?url` imports, WebP sharp 0.35.5 quality85/alpha100 без resize; переписать CSS URLs тем же кешем; `publicDir:false` только для build. Проверка: production сборка и браузер без HTTP ошибок, `resource-sizes.json`: PNG 37 546 783 → WebP 3 041 222 bytes. Ограничение: WebP lossy для RGB, исходные PNG сохранены; это размер этих ресурсов, а не суммарный сетевой трафик или GPU memory.
- Признак: фон/лого загрузки могут не успеть, entry/CSS тоже могут упасть. Способ: inline CSS первый paint; shell assets decode → импорт runtime → все текстуры/UI/font → реальный ready + минимум 1 с видимого времени → reveal. HTML capture error обрабатывает отказ самого entry (Vite не сохраняет onerror исходного module script при переносе в head). Проверка: 4 viewport и 5 отказов/Retry в production tool, unit visible-time/monotonic progress. Ограничение: 90 с timeout после старта entry, до него нет JS-таймера; принудительное завершение браузера не обрабатывается.
- Отдельная серверная публикация использует имеющийся Caddy bind mount, каталог `static/magnet-sort`, route `/magnet-sort/`, собственные releases/current/shared. Не переносить White Tower API, Telegram tokens, storage или его игровые данные. Происхождение логотипа: `public/art/loading/README.md`.
- После первой реальной публикации origin возвращал no-cache даже для assets: общий header внутри handle_path перезаписывал условный. Рабочий способ: взаимоисключающие `@magnet_assets path /assets/*` / `@magnet_fresh not path /assets/*` для обоих root и Cache-Control, без общего fallback внутри subroute. Проверено 2026-10-18: Caddy validate/reload, origin HTTPS и Cloudflare MISS: asset immutable/year, build-info no-cache. Старый CDN-кеш может сохранять прежние headers до истечения; проверять свежий cache key.
