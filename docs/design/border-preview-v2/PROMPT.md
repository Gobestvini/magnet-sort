# Бортики: первое кольцо → второе кольцо → повтор

Дата: 2026-10-12. Built-in image_gen, ui-mockup. Референс стиля: `artifacts/pages-browser/mobile-initial.png`; результат `concept.png`. Макет v1 с заливкой отклонён пользователем. Этот v2 показывает две последовательные фазы одного idle-цикла, а не разные режимы. Интерьеры ячеек остаются кремовыми, светится только бортик цветом магнита.

Уточнение пользователя: «должен подсвечиваться только бордер у всех ячеек; если магнит синий, то синим светом, моргая мягко по очереди: сначала один круг, потом второй и так далее в айдл цикле».

Одобрено пользователем 2026-10-12: «Да, так подходит» в ответ на показ v2 и описание двух последовательных фаз. TASK-0051 переведена в ready; runtime пока не менялся.

Ограничения пробы: статический AI storyboard не доказывает точность hex-маски, мягкость/скорость анимации или перекрытие бортика стопкой. При реализации считать отдельно distance=1 и distance=2 через hexDistance; сначала пульс первого кольца, затем второго, затем повтор. По исходному запросу радиус ограничен двумя шагами. Центр не заливать и не включать в соседние кольца.
