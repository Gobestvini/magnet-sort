# Кампания 1–50

Пять FTUE уровней знакомят с правилами. Уровни 6–50 — фиксированные поля contentVersion 2 с несколькими цветами, препятствиями и ограниченным числом ходов. Runtime ничего не генерирует: JSON содержит начальную позицию и проверенное решение.

| Уровни | Поле | Давление на игрока |
| --- | --- | --- |
| 1–5 | Размещение, притяжение, merge, выбор цвета, цепочка. | Короткое обучение; можно пропустить. |
| 6–10 | 9 фишек трёх цветов, 9–12 препятствий; green появляется на уровне 6. | Решение от 3 ходов. Нужно выбрать положение магнита и порядок очистки цветов. |
| 11–20 | 12 фишек четырёх цветов, 12–15 препятствий. | Решение от 4 ходов, без прежнего запаса 8–12 ходов на один clear. |
| 21–35 | 15 фишек; один цвет имеет массу 10, остальные — по 5; 14–18 препятствий. | Решение от 5 ходов. Несколько групп одного цвета требуют учитывать положение оставшихся фишек. |
| 36–50 | 18 фишек, два цвета с массой 10, 12–18 препятствий и 2–4 ящика, rules v2. | Решение от 6 ходов. Авторский replay обязательно разрушает хотя бы один ящик. |

Каждый ход позволяет выбрать любой из присутствующих цветов. Чужие фишки перекрывают движение. Цель всех новых полей — clearAll. Лимит равен длине сохранённого решения. Это длина найденного решения, а не доказанный оптимум: поиск с ограниченной шириной не перебирает всё дерево.

## Авторинг и проверки

`node tools/rebalance-campaign.mjs` — инструмент офлайн-авторинга. Он записывает статические JSON уровней 6–50, проверяет решение через настоящий simulator и отсеивает поля с частыми случайными победами. После запуска обязательны тесты и браузерная проверка.

`tests/campaign.test.js` проверяет победу всех 50 replays, баланс массы после каждого хода, отсутствие победы за один ход для всех легальных начальных размещений в уровнях 6–50 и случайную игру с независимым seed. Дополнительный прогон использует цвета из решения, но случайные позиции: одного знания порядка цветов недостаточно. Случайные прогоны — регрессионный индикатор, а не оценка сложности для человека. Перебор оптимальных решений и пользовательское исследование не выполнялись.

Новая версия и seed отделяют результаты новых полей от старых рекордов; открытые уровни и настройки сохраняются. Старые ссылки вызовов contentVersion 1 для уровней 6–50 отклоняются существующей проверкой frozen content.
