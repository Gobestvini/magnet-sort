# Кампания 1–50

Кампания объединяет пять FTUE уровней и 45 фиксированных puzzle definitions. Уровень 6 впервые добавляет четвёртый цвет (green). Любой сценарий имеет сохранённый action replay; генерация по seed не используется.

| Уровни | Концепт | Aha | Сложность и ограничения |
| --- | --- | --- | --- |
| 1–5 | Размещение, притяжение, merge, выбор цвета и chain reaction. | Игрок наблюдает, как его действие сдвигает фишку и очищает цель. | Учебная последовательность. Ручная оценка и первый запуск на устройстве не собирались; waiver записан в отчёте FTUE. |
| 6–10 | Один свободный коридор через поле с 6–10 blockers; уровень 6 вводит green. | Поставить магнит за стеком массы 3: стек 2 проходит один шаг, соединяется и очищает 5. | Начальная. Blockers вне проверяемого коридора не меняют короткое решение; это первая версия band, без подтверждённой ручной сложности. |
| 11–20 | Тот же короткий маршрут с конечным лимитом 8–12 ходов. | Пустой ход расходует лимит, поэтому завершение решения за один ход показывает запас. | Начальная. Лимит соблюдён, но не создаёт стратегического давления в authored solution; наращивание сложности требует следующего контентного прохода. |
| 21–35 | На ходе доступны два цвета магнита; только цвет пары двигает стек 2. | Выбрать цвет токенов, а не цвет по умолчанию, чтобы сдвинуть пару к очистке. | Начальная. Контракт выбора проверяется simulator replay; сравнительное ручное тестирование вариантов не проводилось. |
| 36–50 | На пути рядом с очищаемой парой стоит crate; используется rules v2. | Очистка соседней клетки разрушает crate, который блокировал клетки для следующих ходов. | Начальная. Решения проверяют clear → crateDestroyed и сохранение массы; сложность цепочек после открытия прохода пока не проверена пользователями. |

## Данные и replay

Уровни 6–50 хранятся отдельными JSON в `src/levels/campaign/`. Разрешённые blockers, crates и tokens не пересекаются. Для авторского решения проверяются победа, цель, move limit и баланс `remaining token mass + clearedMass === initialMass`. Для каждой начальной позиции есть пустая клетка для placement. Уровни 36–50 содержат crates rules v2; clear adjacent to crate emits `crateDestroyed` after clear.

Первая кампания намеренно остаётся короткой и гарантированно разрешимой. Пороговые тесты статических данных не доказывают полноту пространства решений: exhaustive search всех возможных действий не выполнялся. Отдельного теста на сценарии с полностью занятой доской уже достаточно в simulator; невозможные clear-all кампании отсекаются обязательным replay каждого authored solution. Физический телефон и пользовательские оценки сложности недоступны и не представлены как evidence.
