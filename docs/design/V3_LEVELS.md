## Корректность доказательства

Мемоизированный bounded DFS перебирает допустимые placement по настоящему applyMagnet. Ключ сохраняет координаты, порядок цветов всех элементов, magnets, blockers, cells, clearSize и remainingMoves. Unit ID не влияет на legal placement, BFS, очистку и исход; равнозначные элементы одного цвета безопасно нормализуются только в ключе offline-поиска. Runtime ID остаются уникальными. cleared и turn не меняют доступные продолжения при фиксированном remainingMoves; terminal проверяется до memo.

Есть один точный отсев: если различных оставшихся цветов больше ходов, выиграть невозможно, поскольку за один ход очищается только цвет выбранного магнита. Остальные legal продолжения, включая пустые ходы, обрабатываются рекурсивно. Это полный поиск с доказанным нижним пределом, без эвристического pruning. Выход за maxStates бросает Search unknown и не создаёт доказательство тупика. Достижимые bad-ветки во всех девяти полях завершены без unknown; времена в JSON относятся к конкретному запуску, не к производительности runtime или телефону.

Hint сохраняет прежний контракт: ведёт по основному solution; после отклонения честно сообщает отсутствие подсказки. Новая система подсказок не добавлялась. Ручную/браузерную приёмку и ограничения см. docs/reports/ANIMATION_LEVEL_POLISH.md.
