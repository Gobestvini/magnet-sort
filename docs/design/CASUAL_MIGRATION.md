# Перенос casual-дизайна в Three.js

Референс: [English mockups](mockups/2026-10-09-facebook-casual/index.html), редакция 2.

## План и критерии

1. Собрать основной экран: фиолетовый hex-фон, оригинальный векторный логотип, светлые панели цели/ходов, три объёмных магнита без знаков, Hint/Restart. Английский текст; адаптивный portrait и landscape.
2. Обновить Three.js: тёплые керамические клетки с кромкой, глянцевые кольца с hex-отверстием, насыщенные цвета, читаемые препятствия. Сохранить реальные 25 клеток, raycast и единый RAF.
3. Привести обучение, подсказку, pause/reduced motion, win/loss/retry и ошибку WebGL к общей системе. Использовать живой DOM; счётчики и доступность берутся из state.
4. Сверить screenshots с направлением мокапов и проверить tap/drag/keyboard, reset/pause/resize, все решения и GPU cleanup. Выполнить `pnpm check:full` и browser suite.
5. Зафиксировать результат и оставшиеся ограничения; commit/push.

## Ресурсы и границы

UI собирается SVG/CSS/DOM, поле — процедурное Three.js. Не вырезаем надписи или игровое поле из PNG. Новые логотип/фон/иконки — оригинальные кодовые ресурсы проекта, без сетевых зависимостей. Дизайн адаптируется к настоящему state, а не копирует условную геометрию картинок. Legacy Pixi не меняется. Публикация и Telegram не входят.

## Статус

Первый работающий перенос выполнен: основной экран, Three.js-тема, английские тексты и текущие игровые состояния используют общую систему. План реализован как играбельный срез, с сохранением правил v3. Фактические проверки и границы сходства: [CASUAL_DESIGN](../reports/CASUAL_DESIGN.md).
