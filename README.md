## Запуск здесь

Node.js 22.12+, pnpm, Git. Из `game-template`:

```powershell
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm check:full
```

`start.ps1` также запускает dev server. Открывай адрес из вывода Vite. Кнопки проверяют lifecycle каркаса; игровой механики пока нет.

## Создать отдельную игру

Копируй эту папку в новый каталог вместе с `.agents`, `.github`, `.gitignore` и lockfile. Исключи `node_modules`, `dist`, `artifacts`, `.telegram-*` (кроме `.telegram-bot.env.example`), локальные env и логи. Не копируй родительский `.git`.

Автоматическое копирование с новым именем, без зависимостей/секретов/логов и с `git init`:

```powershell
.\tools\create-project.ps1 -Destination C:\Projects\MyNewGame -Name my-new-game
```

Скрипт требует новый каталог и не перезаписывает существующий проект. Далее команды выполняются из созданной папки. Сам шаблон не содержит product-лицензии; перед распространением выбери лицензию своего кода и проверь условия переносимых навыков/зависимостей.

```powershell
Set-Location C:\Projects\MyNewGame
git init -b main
pnpm install --frozen-lockfile
pnpm check:full
```

Задай имя в package.json и заголовок index.html. Заполни `docs/GAME_BRIEF.md`, затем реализуй одну небольшую играбельную механику в `src/scene.js`. Обнови карту проекта. Настрой собственный remote перед первым push. Вложенная папка здесь не является отдельным Git-репозиторием. Telegram runner разрешён только в отдельном репозитории, чтобы worktree не получил родительскую игру.

## Навигация

- `AGENTS.md` — короткие обязательные инструкции.
- `docs/PROJECT.md` — карта кода и команд.
- `docs/GAME_BRIEF.md` — идея, устройства, стиль и измеримые бюджеты.
- `docs/design/GDD_V0.2.md` — актуальное направление Magnet Sort на PixiJS/pseudo‑2.5D; `PIXI_RENDERING.md` — обязательный контракт рендера.
- `docs/tasks/` — очередь задач Magnet Sort, статусы и шаблон задания другой модели.
- `docs/knowledge/playbook.md` — инженерные практики игр; `pixijs-practices.md` — исследования курсов и практики PixiJS 8.
- `docs/AI_WORKFLOW.md` — выбор сложности модели, контекст, проверки, токены.
- `docs/TEMPLATE_ANALYSIS.md` — анализ переноса и источники улучшений.
- `docs/knowledge/agents/` — пустая память с проверкой SHA-256.
- `docs/TELEGRAM.md` — опциональная очередь через Codex CLI.
- `VERIFICATION.md` — фактические проверки самого шаблона, не новой игры.

`pnpm context -- "тема"` возвращает до восьми актуальных подсказок. `pnpm check` сохраняет полные логи и использует подтверждённый результат для неизменённых входов. `pnpm test:browser` требует Playwright: установи его отдельно или задай `PLAYWRIGHT_MODULE`; нужны браузер и запущенный dev server. Это инструмент разработки, не зависимость игры.

`.github/workflows/check.yml` проверяет новый проект при push/PR. Публикация не включена: выбери её после определения платформы. Каркас не обещает качество готовой игры или фиксированный процент экономии токенов; результаты измеряются на конкретных задачах и устройствах.
